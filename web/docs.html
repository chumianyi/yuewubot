YueWuBot 插件开发文档

一个 zip 包，两个文件，就能给机器人加功能。v1.4.2

一、最小插件

插件就是一个 zip 压缩包，根目录下至少包含：

my-plugin.zip
├── main.py          # 必需，Python 代码
├── m.json           # 必需，元数据 + 钩子 + 指令声明
├── icon.png         # 可选，插件图标（建议 128×128）
└── assets/          # 可选，其他所有文件都放这里
    ├── data.json
    └── template.html
除 main.py、m.json、icon.png 外，其余文件请一律放进 assets/，避免污染插件根目录。

m.json

{
  "name": "weather",
  "version": "1.0.0",
  "author": "YueWu",
  "description": "查询城市天气",
  "homepage": "https://example.com/weather",
  "repository": "https://github.com/example/yuewu-weather",
  "icon": "icon.png",
  "hooks": {
    "on_message": "on_message",
    "on_group_message": "on_group_message",
    "on_private_message": "on_private_message",
    "on_notice": "on_notice",
    "on_request": "on_request",
    "on_startup": "on_startup",
    "on_shutdown": "on_shutdown"
  },
  "commands": [
    {
      "name": "天气",
      "aliases": ["weather", "tq"],
      "description": "查询指定城市天气",
      "usage": "/天气 北京",

    }
  ],
  "config": {
    "api_key": { "type": "string", "label": "接口密钥", "default": "" },
    "unit": { "type": "string", "label": "温度单位", "default": "c" },
    "enabled": { "type": "bool", "label": "启用天气卡片", "default": true }

字段说明

字段类型说明

versionstring版本号
authorstring作者，显示在插件卡片上
descriptionstring一句话简介

iconstring图标文件名，默认 icon.png
hooksobject钩子名对应 main.py 中的函数名
commandsarray指令声明，见下文
configobject配置项 schema，会在控制台自动生成表单

二、钩子（hooks）

钩子函数在 main.py 里定义，可以是普通函数，也可以是 async def。

钩子触发时机参数返回值
on_startup插件加载后bot无
on_shutdown插件卸载 / 程序退出bot无
on_message收到任意消息（指令之后、AI 回复之前）ctx返回 True 拦截，AI 不再回复
on_group_message群消息ctx同上
on_private_message私聊消息ctx同上
on_notice群成员变动、戳一戳等通知ctx无
on_request加好友 / 加群请求ctx无
执行顺序：内置指令插件指令on_group_message / on_private_messageon_message模型对话。任一钩子返回真值即中断后续流程。
群聊里钩子不需要 @ 机器人也会收到消息（可在控制台「插件免 @」关闭）；只有模型对话仍需 @ 或唤醒前缀。因此钩子里请自行判断 ctx.text 是否与自己相关，无关时返回 None 放行。

三、指令（commands）

{
  "name": "天气",              // 指令名，用户输入 /天气
  "aliases": ["weather", "tq"], // 别名，可省略
  "description": "查询城市天气",
  "usage": "/天气 北京",
  "handler": "cmd_weather"      // main.py 中的函数名
}
def cmd_weather(ctx, args):
    city = args.strip() or "北京"
    return ctx.reply("你查的是 " + city)
  • 指令前缀支持 / ／ # ! ！
  • args 是指令名之后的全部文本
  • 群里直接发 /指令 无需 @ 机器人即可触发（仅 / ／ 开头；# ! 在群里不再当指令前缀）
  • 群里 #内容 表示快速对话：剥掉 # 后直接问模型，免 @、不经过指令与插件
  • 已 @ 时未命中任何插件会提示「没有这个指令」；未 @ 的陌生指令静默忽略，不会刷屏

四、Ctx 上下文对象

属性 / 方法说明
ctx.user_id发送者 QQ 号（字符串）
ctx.group_id群号，私聊为空字符串
ctx.message_type"group" 或 "private"
ctx.sender发送者昵称
ctx.text纯文本正文（图片显示为 [图片]）
ctx.images图片地址列表
ctx.raw原始事件字典（QQ 官方的开放平台事件已转换成统一结构）
await ctx.reply(text, at=False)回复文本，at=True 时在群里 @ 对方
await ctx.send_image(src)发送图片，支持 http 链接或本地路径
await ctx.llm(prompt, system=None)调用当前配置的大模型
ctx.cfg本插件的配置项字典
ctx.save_config(values)回写插件配置
await ctx.api(action, **params)QQ 官方版不提供 OneBot 动作接口，调用会抛出 RuntimeError
ctx.bot.ob当前主连接对象（PlatformLink）

QQ 官方机器人能做什么

开源版只走 QQ 开放平台，能力边界由平台决定：

  • 收：群 @ 消息、群消息、单聊消息（网关订阅）
  • 发：文本、图片（图片需公网可访问的 URL）
  • 不做：点赞、禁言、撤回他人消息、好友与入群审批、群成员列表，这些是 OneBot 协议侧的能力

所以插件里不要依赖 ctx.api()，发送统一用 ctx.reply() 与 ctx.send_image()：

async def on_group_message(ctx):
    if "你好" in ctx.text:
        await ctx.reply("你好呀", at=True)
        return True

五、配置项（config）

m.json 里声明的 config 会自动在控制台生成表单，值通过 ctx.cfg 读取：

"config": {
  "api_key": { "type": "string", "label": "接口密钥", "default": "" },
  "limit":   { "type": "number", "label": "每日上限", "default": 10 },
  "enabled": { "type": "bool",   "label": "启用",     "default": true }
}
def on_startup(bot):
    cfg = bot.plugins.plugin_config("my-plugin")
    print("密钥：", cfg.get("api_key"))

配置变更时可选实现回调：

def on_config_changed(values):
    print("新配置：", values)

六、图标与资源

  • icon.png 放在包根目录，控制台插件卡片会直接显示；缺失时用名称首字母代替
  • 其余资源统一放 assets/，用相对路径读取：
from pathlib import Path
ASSETS = Path(__file__).parent / "assets"

def on_startup(bot):
    data = (ASSETS / "data.json").read_text("utf-8")

七、生命周期与内存回收

YueWuBot 采用「用时加载、闲置回收」策略：

  1. 插件启用时 import 进来，注册钩子与指令
  2. 超过设定时间（默认 10 分钟，可在 runtime.plugin_idle_minutes 调整）未被调用，模块会被从 sys.modules 移除并 gc.collect()
  3. 下次消息命中时自动重新加载：指令按 commands[].name / aliases 精确匹配后唤醒，随后立即执行，无需重启
  4. 只靠 on_message 等钩子工作的插件，需在 m.json 中声明 triggers 才能休眠；没有触发词的钩子插件会常驻内存
"triggers": {
  "on_message": ["签到", "打卡"],
  "on_group_message": ["天气"]
}
因此不要把重要状态只放在内存里：需要持久化的数据请写到 assets/ 或插件目录下的文件，并在 on_startup 中重新读取。

八、完整示例

一个每日签到插件，含配置项与图片发送：

# main.py
import json, time
from pathlib import Path

ASSETS = Path(__file__).parent / "assets"
DB = ASSETS / "signin.json"

def _load():
    if DB.exists():
        return json.loads(DB.read_text("utf-8"))
    return {}

def _save(d):
    DB.parent.mkdir(parents=True, exist_ok=True)
    DB.write_text(json.dumps(d, ensure_ascii=False), "utf-8")

def on_startup(bot):
    print("[signin] 已加载")

def cmd_signin(ctx, args):
    db = _load()
    today = time.strftime("%Y-%m-%d")
    rec = db.setdefault(ctx.user_id, {"days": 0, "last": ""})
    if rec["last"] == today:
        return ctx.reply("今天已经签过啦，明天再来～")
    rec["days"] += 1
    rec["last"] = today
    _save(db)
    return ctx.reply("签到成功，已连续 %d 天！" % rec["days"])
# m.json
{
  "name": "signin",
  "version": "1.0.0",
  "author": "YueWu",
  "description": "每日签到，记录连续天数",
  "hooks": { "on_startup": "on_startup" },
  "commands": [
    { "name": "签到", "aliases": ["signin"], "description": "每日签到",
      "usage": "/签到", "handler": "cmd_signin" }
  ],
  "config": {
    "bonus": { "type": "number", "label": "每日奖励积分", "default": 10 }
  }
}

九、打包与安装

  1. 保证 main.py 与 m.json 在压缩包根目录（或单一子目录内）
  2. 执行 zip -r signin.zip main.py m.json icon.png assets/
  3. 控制台「插件」页把 zip 拖进去即可，装好自动启用
限制：单包解压后不超过 10MB，文件数不超过 300，禁止绝对路径与 .. 路径穿越。插件代码以当前用户权限运行，请只安装可信来源的插件。

十、调试

  • print() 与 logging 输出都会进入控制台「日志」页
  • 插件抛出的异常会被捕获并记录，不会中断机器人
  • 改完代码在「插件」页关掉再打开即可热重载，无需重启进程

十二、版本说明

YueWuBot 1.4.1 为纯净版，不含任何 AstrBot 组件，仅支持原生 YueWu 插件，占用最低，适合生产部署。1.4.1 暂未提供 AstrBot 兼容版。

AstrBot 完整兼容版内置移植自 AstrBot 官方源码的插件加载机制（Star 注册表、指令过滤器与装饰器），可直接运行 AstrBot 格式插件，随包附带 AGPL-3.0 许可证原文。

十三、管理员与插件权限

插件卡片右侧的「仅管理员」按钮可以把某个插件设为管理员专用。默认管理员列表为空，添加管理员 QQ 后，只有列表内的账号能调用被限制的插件，其他人使用会收到「权限不足」。

管理员名单在控制台「插件」页顶部维护，也可以用接口读写：

GET  /api/admins
POST /api/admins          {"admins": ["3835347820"]}
POST /api/plugins/<name>/admin  {"admin_only": true}

配置项对应 config.json 的 admins 数组；插件开关保存在 data/plugins.json 的 admin_only 字段。
